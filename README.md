Тензорные вычисления в теории упругости (вариант 1)

Программа восстанавливает матрицу упругости [C] по ультразвуковым измерениям,
вычисляет напряжения, упругую энергию и главные напряжения в 5 точках,
интерполирует поля в произвольную точку Q методом обратных расстояний (IDW),
строит цветовую карту напряжений по Мизесу на сечении z=25 мм.

Запуск:
    python main.py

Требования:
    numpy, matplotlib

Входные данные (в коде):
    - Таблица 1: скорости v1..v7 (км/с → м/с)
    - Таблица 2: координаты и деформации точек P1..P5 (мм, µε)

Настройка:
    - Точка Q: изменить Q = np.array([x, y, z])
    - Сечение: изменить z_target

Результаты:
    - Вывод в консоль: компоненты [C], напряжения, энергия, интерполяция
    - График: цветовая карта σ_vM
